About This Notice

Updated: October 11, 2026.

This notice belongs to an HTML/CSS training project. It is educational sample content, not legal advice or a production privacy policy.

Information Entered in Forms

The contact form includes name, email, phone, company, location, requested service, subject, and message fields. The registration form also includes education, experience, training preferences, skills, profile links, a practice password field, and a CV selection.

There is no connected submission or storage service. Completing these forms does not create an account or deliver an application. Use invented details and a sample file when practicing.

Intended Use

The contact fields demonstrate the information needed to discuss a project. The registration fields demonstrate an internship application workflow. Browser validation checks required values and formats; it does not process a business request.

Basic Data Handling

This project contains no application code for storing submissions, tracking visitors, or writing browser storage. A static host may receive a form request, but the site has no handler that saves or processes it.

If a backend or hosting service is introduced later, its actual collection, retention, security, and access practices must be documented before this sample notice is used as a live policy.

Third-Party Links

Profile links may take you to GitHub or LinkedIn. Those services operate independently and have their own privacy notices. Email links open your chosen email application.

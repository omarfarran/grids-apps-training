# HTML/CSS Reconstruction Practice

Unofficial self-study practice for Omar Farran. Human assessment remains pending. This document gives acceptance criteria only; it contains no solution.

## Brief

Rebuild a small “Studio North” project page with a header/navbar, hero, card grid, and contact form. Work in a separate practice folder rather than modifying completed projects or the final app.

## Acceptance Criteria

- A semantic header contains a brand, three navigation links, and a clear current-page indicator.
- The hero has one page-level heading, supporting text, and a keyboard-accessible call to action targeting the form.
- A project section has a logical heading and three cards, each with a title, summary and meaningful link.
- Cards form one column at 320/390px, two columns at 768px, and three at 1366px.
- A contact form contains labeled name/email/message fields, appropriate input types, required-field indicators and a real submit button.
- Use native form validation; the exercise does not need a backend or an invented submission confirmation.
- Use a centered content width, consistent spacing, readable typography and reusable CSS values.
- Maintain visible focus, readable contrast, logical heading order, meaningful link text and useful image alt text if images are used.
- Navigation, cards and controls fit at all four widths with no horizontal page overflow.
- Long titles and text wrap without covering buttons or breaking the grid.
- The page remains understandable with JavaScript disabled.
- Inspect in browser DevTools and record what you checked; do not mark criteria complete without verifying them.

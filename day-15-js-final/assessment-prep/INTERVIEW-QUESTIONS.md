# Interview Questions — Days 1–14

Unofficial study prompts based on the Foundation topics. Trainer interview, scoring and progression remain pending. No trainer answers are filled here.

## HTML

1. When would you use `main`, `section`, `article`, and `div`?
2. How do headings, labels, input types, buttons, and alt text help accessibility?
3. How does native form validation work, and what still needs JavaScript validation?

## CSS and Responsive Design

4. Explain the box model, specificity, inheritance, and the cascade with a small example.
5. When would you choose Grid over Flexbox? How do media queries change layout?
6. How would you diagnose horizontal overflow, a broken mobile navbar, or a long word breaking a card?

## Bootstrap / Tailwind

7. How do Bootstrap's components/grid differ from Tailwind's utility classes?
8. How would you preserve consistent responsive spacing and visible focus when using either approach?

## JavaScript Fundamentals

9. Explain `const` vs `let`, primitive vs object values, and strict equality.
10. How do conditions, loops, functions, arrays and objects work together in a small application?
11. Compare `map`, `filter`, `find`, `some`, and `reduce`. Which ones return new arrays?
12. What is accidental mutation? How do array/object copies help, and where are shallow copies limited?

## DOM / Events

13. How do `querySelector`, `createElement`, `textContent`, `append` and `replaceChildren` support safe rendering?
14. What do `preventDefault`, event bubbling, delegation, `closest`, and `dataset` do?
15. Why should application state drive rendering instead of treating the current DOM as the database?

## localStorage / JSON

16. What can localStorage store, and how is it scoped to an origin?
17. Why serialize/parse JSON, validate restored records, and catch storage exceptions?

## Async / Fetch

18. What states can a Promise have? How do `.then()` and `.catch()` compare with async/await?
19. Why await both `fetch()` and `response.json()`, and why check `response.ok`?
20. How would you distinguish loading, success, empty, HTTP failure, network failure and invalid JSON?

## Modules / Debugging

21. How do named import/export and `type="module"` work? Why run modules through HTTP?
22. How do you choose module boundaries without creating unnecessary abstraction?
23. Describe your debugging sequence: reproduction, exact error, values/types, root cause, smallest fix, retest.

## Git / GitHub

24. How do working tree, staging, commit, branch, merge, push and pull request differ?
25. What would you inspect with `git status` and `git diff` before committing? How would you avoid including generated files or changes from an unrelated completed project?
